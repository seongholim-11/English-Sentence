## 1. 계정 준비 (먼저 시작하세요 — 승인에 시간이 걸릴 수 있어요)

1. **Apple Developer Program** 가입 (연 $99). 개인으로 가입하면 앱스토어에 본인 이름이 판매자로 표시돼요.
2. https://appstoreconnect.apple.com 에서 약관에 동의하고 "앱" 메뉴가 열리는지 확인.
3. 컴퓨터에 EAS CLI 설치: `npm install -g eas-cli` 후 `eas login` (Expo 계정 필요, 무료).

## 2. 앱 등록 (App Store Connect)

"앱 → +" 로 새 앱을 만들어요.

| 칸 | 넣을 값 |
| --- | --- |
| 플랫폼 | iOS |
| 이름 | `링고루프 - 영어 회독` (이미 쓰는 이름이면 거절돼요 → 대안 이름 필요) |
| 기본 언어 | 한국어 |
| 번들 ID | `com.damadu.lingoloop` (처음엔 목록에 없을 수 있어요. `eas build`가 만들어 줘요) |
| SKU | 아무 고유 문자열 (예: `lingoloop-ios-1`) |

이어서 **앱 정보 / 가격 / 개인정보** 를 채워요. 값은 `docs/store-listing.md`에 있어요.

- 부제, 카테고리(교육 / 참고 자료), 키워드, 설명, 프로모션 텍스트: 그대로 붙여 넣기
- **지원 URL**: `https://seongholim-11.github.io/English-Sentence/support/` (자주 묻는 질문과 문의 안내가 있는 공개 페이지)
- **개인정보처리방침 URL**: 위 주소
- **저작권**: `2026 seongholim`
- **가격**: **무료로 결정됨.** 유료나 인앱 구매를 쓸 때만 "계약·세금·금융 정보" 설정이 필요해요. 무료면 필요 없어요.
- **앱 개인정보(App Privacy)**: "데이터를 수집하지 않음" 선택. 앱에 계정·분석·광고 SDK·서버 전송이 없어요.
- **수출 규정**: 이미 `ITSAppUsesNonExemptEncryption: false`로 설정돼 있어 추가 질문이 나오지 않아요.
- **연령 등급 설문**: `docs/store-listing.md`의 "연령 등급 설문 답변" 표대로 정직하게 답해요. **목표는 13+**(예문은 그대로 유지). 계산 결과가 13+보다 낮게 나오면 더 높은 등급을 직접 고를 수 있는지 확인하세요.
- **스크린샷**: 6.9인치 iPhone 6장, 13인치 iPad 6장. `docs/screenshots/` 사용 (실기기 캡처로 바꾸면 더 안전).
- **헤더·검색 결과 이미지**: `docs/store-previews/header-search/`에 알파 채널 없는 PNG(RGB) 3종이 있어요. 칸이 하나(유니버설)면 `universal-5244x2950.png`(16:9, PNG만 허용), 헤더와 검색 결과가 따로면 `header-3840x1646.png`(21:9)와 `search-result-3840x2560.png`(3:2). 중요한 요소는 Apple이 정한 가운데 안전 영역 안에 있어요. 소스는 `src/header.html`, 다시 만들기는 `src/capture-header.mjs`.
- **심사 메모(App Review Information)**: 아래 문구를 붙여 넣으세요.

```
로그인이나 계정이 필요 없는 오프라인 학습 앱입니다. 모든 영어 음성은 앱에 포함되어 인터넷 없이 재생됩니다.

```

연락처(이름·이메일·전화)는 심사팀용이며 앱스토어에 공개되지 않아요.

## 3. 빌드와 업로드 (Windows에서도 가능, Mac 불필요)

프로젝트 폴더에서 한 줄씩 실행하세요.

```
eas init
eas build --platform ios --profile production
eas submit --platform ios --latest
```

- `eas init`: Expo 프로젝트를 만들고 `app.json`에 프로젝트 ID를 추가해요. 이 변경은 커밋하세요.
- `eas build`: Apple 로그인(Apple ID, 2단계 인증)이 필요해요. 인증서와 프로비저닝은 EAS가 자동으로 만들어 줘요. 클라우드에서 빌드하고 시간이 몇 분~수십 분 걸려요.
- `eas submit`: 빌드를 App Store Connect로 올려요. 처리(Processing)가 끝나면 TestFlight에 나타나요.

## 4. TestFlight로 실기기 점검 (제출 전에 꼭)

TestFlight 앱으로 설치해서 아래를 확인하세요. 문제가 나오면 알려 주세요. 제가 고칠게요.

- [ ] 첫 실행: 로딩 후 홈에 "처음이세요?" 안내가 보이고, "영단어 1세트 시작하기"가 동작
- [ ] **무음 스위치를 켠 채** 단어·예문·대화문 음성이 나오는지 / 비행기 모드에서도 나오는지
- [ ] 대화문 전체 듣기를 끝까지 들어 보기, 도중에 뒤로 가기·다른 편으로 이동
- [ ] 복습 알림: 권한 허용 → 시각 변경 → 앱 종료 후 그 시각에 알림이 오는지, 거부했을 때 안내
- [ ] 작은 iPhone(SE 등)에서 글자 크기 "아주 크게" + 기기 설정 글자도 크게: 학습·퀴즈·대화문·설정이 잘리지 않는지
- [ ] 한 손 조작: 대화문 아래 버튼(전체 듣기, 가리기, 다 외웠어요)이 엄지에 닿는지, 버튼 크기가 작아서 오터치가 없는지
- [ ] 카드를 빠르게 연타해도 한 장씩만 넘어가는지, "직전 채점 취소"가 동작하는지
- [ ] 세트 크기를 바꿨을 때 덱·홈·이어서가 맞는지
- [ ] 백업 내보내기 → 공유 시트에서 복사 → 가져오기에 붙여 넣기 → 미리보기 → 복원
- [ ] 앱을 완전히 종료했다 다시 열었을 때 기록이 유지되는지, 처음 실행 속도가 괜찮은지
- [ ] 설치 용량(음성 약 29.6MB 포함)이 괜찮은지
- [ ] iPad를 쓸 거라면 세로 화면에서 가운데 열 레이아웃이 괜찮은지 (마음에 안 들면 `supportsTablet: false`)

## 5. 제출

1. App Store Connect에서 빌드를 버전 1.0.0에 연결.
2. "이 버전의 새로운 기능"은 `docs/store-listing.md`의 문구 사용.
3. 모든 필수 칸에 빨간 표시가 없으면 "심사를 위해 제출".
4. 심사는 보통 수일 걸린다고 알려져 있어요(정확한 기간은 장담할 수 없어요). 결과는 이메일과 앱 화면에 나와요.

## 6. 거절됐을 때 자주 나오는 이유와 대비

| 이유 | 이 앱의 대비 |
| --- | --- |
| 개인정보처리방침 URL이 안 열림 | 현재 열림 확인. GitHub Pages가 켜져 있어야 해요 |
| 최소 기능(4.2) — 웹 앱 같음 | 오프라인 음성, 알림, 간격 복습, 백업 등 앱 기능이 있어요. 심사 메모에 적었어요 |

| 메타데이터 불일치 | 스크린샷은 실제 앱 화면과 같아야 해요. 실기기 캡처 권장 |
| 연령 등급 | 설문을 정직하게 답했는지 |
| 이름 중복·상표 | 앱 이름을 등록할 때 알려 줘요 |

## 7. 출시 후 업데이트

- 코드 수정 → `eas build --platform ios --profile production` → `eas submit` (빌드 번호는 자동으로 올라가요).
- 버전 번호를 올리려면 `app.json`의 `version`을 바꾸세요.
- 개인정보 관련 기능(계정, 분석, 광고)을 추가하면 개인정보처리방침과 App Privacy 답변을 먼저 고쳐야 해요.

## 8. 알려진 한계 (출시를 막지는 않아요)

- 알림 문구가 고정이에요(정해진 시각 반복 알림이라 복습 장수를 넣을 수 없어요).
- 앱의 백업은 파일 선택이 아니라 복사·붙여넣기 방식이에요.
- 스플래시 화면은 기본 설정이에요.
- 안드로이드는 출시 준비를 하지 않았어요(Google Play 등록 1회 $25, 별도 빌드 필요).
- iPad는 지원하기로 했어요(폰 폭의 가운데 열로 표시). iPad 13인치 미리보기는 `docs/store-previews/ipad-13/`에 있어요.
- 영단어 덱 데이터는 CC BY-SA 4.0 자료를 바탕으로 해서 같은 조건으로 공유해야 해요. 적용 범위는 출시 전에 한 번 직접 검토해 주세요(`NOTICES.md`).
