# 링고루프 앱스토어 미리보기

최종 PNG 8장: `../iphone-6.9/01-loop.png` ~ `08-stats.png`.
각 1320×2868 px. `../pair-check.png`는 2640×2868 px, `../overview.png`는 전체 축소 보기.
`../index.html`에서 8장의 원본을 클릭해 확인할 수 있다.

## 제작 방식

AI 이미지 생성 없이 HTML/CSS/SVG와 실제 앱 스크린샷을 합성했다.
`build.mjs`가 프로젝트의 IBM Plex Sans KR, Space Grotesk, 앱 아이콘, 스크린샷 6장을 데이터 URL로 포함한 `previews.html`을 만든다.
`previews.html?slide=pair`는 2640px 너비의 연속 디자인이며 `&half=2`는 오른쪽 절반을 표시한다. 나머지 슬라이드는 `?slide=3` ~ `?slide=8`.

ego-browser의 deviceScaleFactor 1, 1320×2868 뷰포트, Page.captureScreenshot의 clip.scale 1로 저장했다.
`round-01.mjs`는 8장 캡처, `round-02.mjs`는 최종 하단 배치·연결 보기·전체 보기·검증 파일 생성 코드다. TaskSpace 번호는 해당 실행에서 발급된 번호로 바꿔야 한다. `round-03.mjs`는 연결 보기 생성의 복구 실행 기록이다.

## 확인 결과

- 8장 모두 1320×2868 PNG. 한글 폰트 로딩 및 이미지 디코딩 성공, 헤드라인/부제 텍스트 가로 넘침 없음.
- 실제 앱 화면 6장, 참고 이미지 10장, 최종 8장과 연결 이미지 육안 확인.
- 첫 두 장을 이어 붙인 경계 16px 영역을 2640px 연속 브라우저 렌더링과 비교: 수정본은 차이가 있는 색상 채널 220개, 채널 차이 최대 1/255. 시각적인 경계 어긋남 없음.
- 학습·대화 화면의 하단 주요 버튼을 유지하고 폰 끝부분은 의도적으로 잘랐다.
- 01·02 수정: 폰을 180px 올리고 칩을 오른쪽으로 이동했다. 칩 블러는 제거하고 단색 반투명 배경으로 바꿨다.
- 07 수정: 헤더 바로 아래의 잘린 말풍선 조각만 앱 배경색으로 덮었다. 원본 앱 스크린샷 파일과 나머지 대화 내용은 보존했다.
- `fix-01.mjs`로 수정본을 캡처했다. 다른 5장(03·04·05·06·08)은 SHA256 해시 일치로 변경 없음을 확인했다.
- 이 폴더 밖의 파일 변경, 커밋, 푸시 없음.
