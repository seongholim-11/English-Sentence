다시봄 개인정보처리방침

시행일: 2026년 11월 9일

‘다시봄’(이하 “앱”)은 영어 단어·구동사·문장·대화문을 반복해서 익히는 학습 앱입니다. 앱은 이용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

1. 수집하는 개인정보

없습니다. 회원가입이나 로그인이 없고, 이름·연락처·위치·사진·연락처 목록·광고 식별자를 요청하지 않습니다. 분석 도구, 광고 SDK, 크래시 수집 도구도 넣지 않았습니다.

2. 기기에 저장되는 정보

학습을 이어 가기 위해 아래 정보가 이용자의 기기 안에만 저장됩니다. 개발자나 제3자는 이 정보를 받지 않습니다.

  • 학습 기록: 회독 진행 상황, 외운 카드, 복습 일정, 퀴즈 결과, 즐겨찾기, 연속 학습일
  • 설정: 하루 목표, 발음 속도, 자동 재생, 화면 테마, 글자 크기, 복습 알림 시각

앱을 삭제하면 이 정보도 함께 삭제됩니다. 기기를 바꾸면 옮겨지지 않습니다.

3. 알림

이용자가 설정에서 복습 알림을 켠 경우에만 알림 권한을 요청합니다. 알림은 기기 안에서 정해진 시각에 표시되는 로컬 알림이며, 알림을 위해 서버로 보내는 정보는 없습니다. 권한은 기기 설정에서 언제든 끌 수 있습니다.

4. 발음 듣기

영어 발음은 기기에 내장된 음성 합성 기능으로 재생됩니다. 앱은 발음을 위해 별도의 서버로 텍스트를 보내지 않습니다.

5. 웹 버전

웹 버전은 GitHub Pages에서 제공됩니다. 학습 기록은 사용 중인 브라우저의 저장소에만 저장됩니다. 페이지를 불러올 때 호스팅 제공자(GitHub)가 접속 기록을 처리할 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.

6. 제3자 제공 및 국외 이전

수집하는 개인정보가 없으므로 제3자에게 제공하거나 국외로 이전하는 정보도 없습니다.

7. 아동의 개인정보

앱은 연령과 관계없이 개인정보를 수집하지 않습니다.

8. 이용자의 권리

저장된 정보는 모두 기기 안에 있으므로, 앱의 데이터를 지우거나 앱을 삭제하는 것으로 언제든 삭제할 수 있습니다.

9. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 알립니다. 앱이 개인정보를 수집하도록 바뀌는 경우에는 그 전에 앱 안에서 알립니다.

10. 문의

문의는 GitHub 이슈로 남겨 주세요.
